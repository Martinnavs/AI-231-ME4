
BACKGROUND. We build a spoken voice assistant (a small local router model, Gemini 3.1 flash-lite with Google Search grounding, Tavily search). Before answering, a GATE must decide whether a user question needs a web lookup and a cited source, because its answer can have changed since the model's training (who holds a role, prices, versions, scores, "latest", local facts) or because the entity is obscure. Today the gate is one regex; on FreshQA's 600 labelled questions it flags only 55% of changing questions (77% of fast-changing, 40% of slow-changing) with 21% false alarms on never-changing ones. We want a better gate.

ALREADY EXAMINED (do not report as new): Adaptive-RAG's T5-large complexity classifier (labels A/B/C by hop count, no released checkpoint, 54.5% accuracy), FreshQA's four classes, SituatedQA's static/TEMP/GEO classes, Self-RAG reflection tokens, FLARE, Gemini's old dynamic_threshold (not documented for Gemini 3).

HARD CONSTRAINTS for anything we would adopt: it must run on a laptop CPU in at most about 50 ms per question (the agent server then calls Gemini; the whole turn budget is about 2 s), must never need to run on a Raspberry Pi, must not call an LLM (no extra model call per question), has a licence we can use in a class project (Apache-2.0, MIT, BSD, CC-BY or similar; say if non-commercial or unclear), and a small footprint (under about 500 MB). Training our own on a few thousand labelled questions is acceptable; fine-tuning a small encoder is acceptable.
