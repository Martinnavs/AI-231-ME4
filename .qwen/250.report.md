# 250 report: sufficiency check after an accepted document answer (flagged off)

Branch `exp/sufficiency`, worktree `~/AI-231-ME4-w250`.

## The problem

(1) A spoken document answer sometimes does not address the actual question (an info
dump). (2) The agent never assessed, for an ordinarily worded question, whether the
documents alone are enough or the web must supplement (the answer is from an older
period, or one half of a normal question is outside the documents). (3) The owner
wanted a stronger second check. Today an accepted document answer is spoken as is,
never checked for sufficiency.

## What changed

### 1. `pipeline/src/voice_pipeline/sufficiency.py` (new)

- `SUFFICIENCY = False` kill-switch (off by default; the tests monkeypatch it on; the
  experiment flips it later).
- `async def verdict(request, question, answer, source_year, today) -> Verdict | None` —
  ONE call to `request(system, user)`, the same cheap JSON model the document lane uses
  (`JsonRequest` from ask_documents), capped at `VERDICT_TIMEOUT_S = 1.5`. Any error,
  timeout or unparsable reply → None (fail-open: nothing extra is said). Reply shape:
  `{"verdict": "sufficient"|"stale"|"missing_half"|"wrong_question", "web_question": ...,
  "reason": "<=12 words"}`. The system prompt is generic English, evidence-only (it sees
  only the question, the spoken answer, the source year if known, and today's date;
  "never your own knowledge"), with three synthetic examples on the invented entities
  (Zorblat bureau / Keira Moss / Quenth river, continuing the 247 family) and invented
  years — no test-corpus words anywhere in the module. The prose defines each verdict and
  says "the normal case: when in doubt, sufficient" (over-triggering is the main risk).
- The cheap gate (`should_check`, `time_sensitive`, `source_earlier`): the call is paid
  for only when ANY of — the question is time-sensitive (`gemini_grounding.changeable`
  when the root package is importable without network, else a local word-bounded regex of
  present/next/latest/current/now/this year/month/today/still); the source year is known
  and from an earlier period than today's (a fiscal year like FY26 is compared against the
  fiscal year today falls in, July start); or the answer is shorter than 6 words. The
  caller is only the accepted document routes, so pleasantries and non-document turns
  never pay for it.
- `HEDGE_TAIL` — the web lookup's honest hedge, copied as in compound.py/evaluators.py
  (a lookup that comes back this way has not actually checked the web); pinned to
  `evaluators.HEDGE` by a test.

### 2. `pipeline/src/voice_pipeline/agent_server.py` (small, local)

- `__init__`: `self._sufficiency_attempted = False`; `handle` resets it per turn right
  next to `_compound_attempted` — the check runs at most once per turn.
- New helper `AgentServer._maybe_supplement(said, doc_result, speak, on_text)`:
  - the verdict is started as `asyncio.create_task` BEFORE the document answer is spoken
    (first audio is never delayed);
  - the document answer is spoken as today (the passed `speak` coroutine of
    `self.spoken(...)`), byte-for-byte as before;
  - the verdict task is then awaited with `AWAIT_TIMEOUT_S = 2.5`;
  - stale / missing_half with a non-empty `web_question`: `await self.lookup("web_answer",
    {"query": web_question})` (the same lookup as everywhere else, so the ledger, the
    hedge and the directness check apply; capped at `WEB_TIMEOUT_S = 4.0`). If the text
    exists and is not the hedge, ONE supplement sentence group is spoken after the answer,
    worded as an addition, never a retraction: stale → "The web has a newer figure: <web>";
    missing_half → "From the web: <web>". The supplement is appended to `result["text"]`
    so the turn log keeps what was spoken.
  - wrong_question: the web is checked but the result is logged (`_logger.info`), never
    spoken.
  - sufficient / None (failure, timeout, garbage) / hedged web / failed lookup: nothing
    more is spoken.
  - The turn row is recorded with `sufficiency: <verdict|"none">`, `sufficiency_web:
    true|false`, `sufficiency_s` whenever the check was paid for.
- Both places where an accepted docs answer is spoken with route "docs" (the no-router
  and the router branch of `handle`) now build the turn through
  `self._maybe_supplement(said, doc_result, self.spoken(...), on_text)`. A source test
  pins exactly two call sites. The legacy `doc_race` lane (`_try_docs_first`) and the
  search_docs routes are untouched, per the ticket's non-goals.

### 3. `pipeline/pyproject.toml`

- mypy override extended with `voice_agent` / `voice_agent.*` (next to the existing
  `pipecat` override): the root project is another package and venv; the sufficiency gate
  may import its classifier, lazily guarded.
